# ExpenseMate — Personal Expense Tracker

A personal finance dashboard built with Python and Streamlit to track expenses, analyze spending habits, and manage a monthly budget.

## Features

- **Expense management:** Add and delete expense records.
- **Monthly reports:** Filter expenses by month and review total spending.
- **Budget monitoring:** View remaining budget and receive alerts when spending approaches or exceeds the budget.
- **Interactive visualizations:** Explore spending patterns through charts.
- **CSV export:** Download expense data for further analysis.
- **Local data storage:** Store expense records using SQLite.

## Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Tanmay-web300/ExpenseMate-Portfolio.git
   cd ExpenseMate-Portfolio
   ```

2. Create and activate a virtual environment (optional but recommended).

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   streamlit run ExpenseMate.py
   ```

5. Open the local URL shown in your terminal.
